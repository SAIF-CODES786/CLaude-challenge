# Day 17 – E85 Vehicle Cost Analysis Dashboard

## Objective
Built an interactive HTML dashboard to analyze vehicle fuel economics using a CSV dataset. The dashboard compares Petrol, Diesel, CNG, EV, and E85 on cost, maintenance, CO₂ emissions, and overall efficiency.

## Vehicle Details
- Vehicle: Maruti Suzuki Swift VXI
- Fuel: Petrol
- Usage: Mixed
- Distance: 1000 km/month
- Vehicle Age: 3 years

## Features
- KPI Cards
- Cost per km comparison
- CO₂ emissions comparison
- Age vs Cost analysis
- E85 Score Gauge
- Fuel comparison cards
- Responsive glassmorphism UI
- Pure SVG charts (No CDN)

## Key Findings
- Petrol average cost: ₹6.21/km
- E85 average cost: ₹6.37/km
- Monthly fuel cost: ₹6210
- Break-even E85 price: ₹79.11/L
- E85 Score: 5.7/10
- EV has the lowest running cost.
- CNG provides the best balance between cost and emissions.
- E85 has lower CO₂ emissions but higher running cost than Petrol.
